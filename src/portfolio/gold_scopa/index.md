## About

_Gold Scopa_ is an online version of the classic Italian card game _Scopa_. It's a passion project of mine and something I would love to release one day. The bulk of the game is done; it just needs proper card art.

![](Media/gold_scopa.gif)

## What I've done

I've worked quite a bit on the game and it's in a good state. This work includes:

* _Scopa_ card game logic
* Opponent AI
* Multi-round games and score keeping
* UI
* Music
* Sound effects
* Animations
* Visual design

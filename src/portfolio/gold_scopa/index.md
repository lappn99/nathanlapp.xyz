# Gold Scopa

## Engine

Godot



---

## About

_Gold Scopa_ is a online version of the classic Italian card game _Scopa_. This is a passion project of mine and is something I would love to release one day. The bulk of the game is done, but I just need proper cards for the art. 

![](Media/gold_scopa.gif) 

---

## What I've done

I've worked quite a bit on the game and it is in a good state. This work includes:

* _Scopa_ card game logic
* Opponent AI
* Multi round games and score keeping
* UI
* Music
* Sound Effects
* Animations
* Visual Design
